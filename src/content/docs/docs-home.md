## 简介

QtEasyTier 是一个基于 EasyTier 后端，使用 Qt 框架开发的异地组网工具，用于创建和管理虚拟网络连接。它提供了直观的图形界面，帮助用户轻松配置和管理虚拟网络，实现跨网络设备的安全通信。QtEasyTier 是一个去中心化的组网工具，每个节点平等对立，为用户提供更加安全，可靠，低成本的异地组网服务。

QtEasyTier 致力于为用户提供更加简单，方便，高效的 EasyTier 去中心化组网服务。努力做到让小白快速上手，为大佬优化体验。并推出了一些特色功能：

- CIDR 计算器：帮助用户快速计算 IP 地址范围以及根据范围生成 CIDR，方便配置子网代理。
- 公共节点列表：收录部分公共节点，方便用户一键添加。
- 一键联机：联机无需复杂配置，自动生成房间号，小白也能轻松上手
